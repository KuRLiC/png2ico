# png2ico

A simple Python script to convert PNG images to ICO format.

## Requirements

- Python 3.x
- Pillow library

## Installation

You can install the required library using pip:

```bash
pip install Pillow
```

or using the requirements file:

```bash
pip install -r requirements.txt
```

## Usage

To convert a PNG image to ICO format, run the script with the input PNG file and the desired output ICO file:

```bash
python png2ico.py input.png 
```
